# 🚗 Core-4 Drive — AI運転アシスタント「Neuro」

> **AIが運転をサポートし、危険情報を共有して安全運転を実現するスマートカーコックピットのプロトタイプ**

PyQt5で構築されたフューチャリスティックなダークテーマのスマートカー・ダッシュボードです。
車内AIアシスタント「Neuro」が音声・チャットで対話し、地図・天気・ナビゲーションを提供します。

> ⚠️ **本プロジェクトはプロトタイプ・デモ用途です。**
> 地図・天気・ルート案内は実際のAPIを使用しますが、速度・燃料・バッテリー・危険情報はデモ用シミュレーションです。詳細は[実データ vs シミュレーション](#-実データ-vs-シミュレーション)を参照してください。

## 🤖 Neuro AI — オフラインファースト構成

Neuroは**4段階のパイプライン**で、最速の方法を自動選択します：

```
ユーザー入力
   ↓
① インテントルーター   → 即時応答（速度・音楽・ナビ等のコマンド）
   ↓ 一致しない場合
② NeuroAI ルールベース → 即時応答（計算・挨拶・簡単な会話）
   ↓ 確信度が低い場合
③ Ollama (qwen2.5:1.5b) → ローカルLLMで自由会話（オフライン・無料）
   ↓ Ollamaが無い場合
④ Claude API           → クラウドAI（任意・APIキー必要）
```

- **インターネット不要**で動作（①②③）
- 小型モデル向けに **Few-shot例** で応答品質を最適化
- 会話履歴を保持した**マルチターン対話**

## 📊 実データ vs シミュレーション

| 項目 | 状態 | 説明 |
|------|:----:|------|
| 地図表示 | ✅ 実データ | OpenStreetMap（無料・キー不要） |
| 天気情報 | ✅ 実データ | Open-Meteo API（設定した現在地から取得） |
| ルート・距離・ETA | ✅ 実データ | OSRM（実際の道路ネットワーク） |
| 地名検索 | ✅ 実データ | Nominatim（世界中対応） |
| AI会話 | ✅ 実装済み | Ollama または Claude API |
| 現在地 | ⚙️ 手動設定 | 📍ボタンで地名を入力して設定。未設定時はIPアドレスから推定 |
| 速度データ | 🎭 シミュレーション | CSVファイルから再生、またはランダム生成 |
| 燃料・バッテリー | 🎭 シミュレーション | 固定値・ランダム変動 |
| 事故リスク | 🎭 シミュレーション | 速度から算出した推定値 |
| 周辺車両・危険情報 | 🎭 シミュレーション | デモ用固定データ |
| ニュース | 🎭 シミュレーション | コード内の固定リストからランダム表示 |
| 音声認識 | ☁️ Google STT | インターネット接続が必要 |

## 💬 使い方の例

### 現在地を設定する
右パネルの検索欄に現在地名を入力 → **「📍」ボタン**を押す：
- `東京` / `大阪` / `名古屋` など、任意の地名
- 設定は `neuro_config.json` に保存され、次回起動時も引き継がれる

### 音声で話しかける
1. **「Hey Neuro」ボタン**を押す（または🎤で常時待機ON）
2. 話しかける：
   - 「今の速度は？」
   - 「東京タワーまで案内して」
   - 「今日の天気は？」
   - 「音楽かけて」

### チャットで入力する
下部の入力欄に直接入力：
- 「渋谷に行きたい」
- 「事故リスクは？」
- 「1+1は？」

### 目的地を検索する
右パネルの検索欄に地名を入力 → **「案内」**：
- `東京タワー` / `大阪城` / `京都駅` など、世界中の任意の地名
